# CLAUDE.md — rules for Claude (and any agent) working in C:/channel

Project: faceless, quality-first explainer Shorts (9:16, 1080x1920 @30 fps, 30–45 s).
Full spec: docs/MASTER_PLAN.pdf (authoritative). Tooling decisions: config/pipeline.json.
Kit provenance + local-change log: docs/vendor-notes.md.

## Always
- One stage at a time. Read `videos/<id>/state.json` first; update it last.
  Write outputs to files. Never rely on chat memory.
- Stop at gates 1–4 and wait for approval. Never skip a gate.
- Python: ALWAYS `C:\channel\.venv\Scripts\python.exe` by absolute path. Never global.
- Work only inside this folder. Ask before deleting anything, downloads >500 MB,
  or system changes. Never as administrator.
- Commit to git before each stage and after each approved gate (tag gate<N>-<id>).

## Pipeline v2 rules
- Time is integer frames at `fps`. `videos/<id>/master.json` is the ONLY timing source.
- Never hand-edit `timeline/words.json` or `words.frames.json` — generated by align/P4.
- Plugin (studio/) draws pictures only: captions/fades/music/sfx OFF (make_plugin_files.py).
- Remotion owns captions, overlays, transitions between segments, GradeOverlay and
  final audio (one <Audio>, audio/mix.wav).
- Do not run the plugin's own skills (make-2d-video, new-video, …). Use ch-* skills
  and the vendored references in docs/vendor/references/.
- Do not edit studio/ kit files except studio/engine/styles.js (brand style); log any
  change in docs/vendor-notes.md.
- Reuse studio/shared/ sets/props/recipes before writing new ones.
- Run pipeline/validate.py before every render; after 3 failed fix attempts STOP and report.

## Content
- Facts need sources.json entries (≥2 independent sources for key claims, dates on
  numbers, uncertain marked). No accusations about real people beyond documented facts.
  Cast real persons as generic figures or off-screen; label recreations as illustration.
- Follow brand/brand.md for tone/voice/palette/motion. Do not invent styles per video.

## Assets
- Only files in library/ with a license record in library/licenses.json. Unknown
  license ⇒ do not use, tell the human. No AI-generated images. No commercial music.
- Attribution lines flow into publish.md automatically (ch-publish reads master.attributions).

## Renders (8 GB laptop — be conservative)
- Two renderers never run at the same time. Plugin `--workers 2`, Remotion concurrency 2.
- Drafts at `--scale 0.5`; jpeg capture (`--format jpeg`) for drafts/QC.
- Range renders `--from/--to --out` for fixes; Mode B when Remotion owns ≥30%.
